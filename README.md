# Amazon-Inspired Sign-In UI | HTML & CSS

A static frontend recreation of a sign-in interface, built to practise page structure, form layout, and visual styling.

> **Educational project only.** This is not affiliated with or endorsed by Amazon. It does not support real sign-in or account creation.

## Technologies
**HTML5 · CSS3**

## Interface Highlights
- Email/mobile input layout and Continue button.
- Conditions of Use and Privacy Notice links.
- Business-account section.
- Logo and favicon integration.
- Styling focused on spacing, alignment, and readability.

## Development Focus
- Structuring a sign-in page with HTML.
- Styling form elements and page sections with CSS.
- Recreating a familiar interface while keeping the implementation frontend-only.

## Run Locally
1. Clone or download this repository.
2. Open the project folder.
3. Open the HTML entry page in a web browser.

## Scope & Limitations
This is a static UI practice project. It has no backend, authentication, account creation, or credential processing.
